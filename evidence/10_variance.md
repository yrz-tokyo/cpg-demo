# 測定のばらつき — 「その差は誤差では？」への答え

## なぜ測ったか

統治前後で 63% → 84%（衝突ありの問いは 38% → 86%）という差が出た。
Genie は非決定的なので、**同じ状態でも実行ごとに答えが変わる**。
差がその揺れの範囲内なら、何も示せていないことになる。
そこで**統治後の状態のまま、同じ49問を繰り返し**聞いた（計3回）。

## 結果（3回測定した）

最初の2回は IP ACL のブロックで途中で止まったため、完走した問だけで比較している。
停止した run を集計に混ぜないよう、ハーネスが2問連続のブロックで自動停止する。
3回目で49問を完走した。

| 測定 | 比較できた問 | 正答率の差 | 判定が変わった問い |
|---|---|---|---|
| 1回目 | 27問（IPブロックで停止） | **−3.7 pt**（77.8% → 74.1%） | **3 / 27（11%）** |
| 2回目 | 37問（IPブロックで停止） | **±0.0 pt**（78.4% → 78.4%） | **6 / 37（16%）** |
| 3回目 | **49問 完走** | **+4.1 pt**（83.7% → 87.8%） | **6 / 49（12%）** |

3回目だけ注意が必要で、**この run の前に FI-F-05 の統治の欠陥を1つ直している**
（財務の instruction に `mart_revenue_reconciliation` の粒度を明記した。
詳細は `BUILD_LOG.md`「測定後に直した統治の欠陥」）。
したがって +4.1 pt のうち **1問（+2.0 pt）は修正の効果で、揺れではない**。

内訳: 正解になった4問のうち `FI-F-05` は修正によるもの。
残りは `FI-F-03` / `SA-F-01` / `XD-04` が正解へ、`MK-M-06` / `XD-07` が不正解へ動き、
**正味 +1問 = +2.0 pt** がこの run の揺れ。

## 読み方

**集計は安定している。個別の問いは揺れる。**

2回目では6問の判定が変わったが、**3問が正解に・3問が不正解に**動いて相殺し、
全体の正答率は 1問も変わらなかった（29/37 → 29/37）。
つまり揺れは**特定の方向を持たない**。

3回目（49問完走）でも**正本参照率は 36/49 → 36/49 で完全に一致**した。
判定が変わった6問のうち修正由来の1問を除くと、正味の揺れは +2.0 pt。

| | 値 |
|---|---|
| 同じ状態の正答率の揺れ | **0.0 〜 3.7 pt**（3回測定: −3.7 / ±0.0 / +2.0） |
| 統治前後の差（全体） | **+21 pt** → 揺れの **5.7倍以上** |
| 統治前後の差（衝突あり） | **+48 pt** → 揺れの **13倍以上** |

**+21pt も +48pt も、この揺れでは説明できない。**

## 揺れた問いの素性

揺れたのは11問（3回合計・重複あり）で、**素性が揃っている**。

| 問 | 揺れた理由 |
|---|---|
| `SA-F-01` 受注推移 | 「推移」に集計単位を書いていない。月次で集計するか受注1件ずつ返すかが実行ごとに変わる |
| `TR-F-04` 来月の販促イベント | 「開始予定」から status や通貨で絞るかどうかが実行ごとに変わる |
| `TR-F-01` / `TR-F-02` 控除 | 係争中の判定列が2つある（`deduction_status` と `dispute_flag`）ことに起因 |
| `MK-M-01` / `MK-M-02` マーケ投下額 | USD と JPY の換算を答えに含めるかどうかが揺れる |
| `TR-M-04` 精算率 | 率を % で返すか比率で返すかが揺れる |
| `FI-F-05` / `XD-04` | 集計の粒度（得意先別か全社か）の解釈が揺れる |
| `MK-M-06` 消費者調査費 | 「含まれますか」に対し、別物だと説明しつつ合算額も併記するかが揺れる |
| `XD-07` dollar_sales | 同じく boolean。否定の言い回しが実行ごとに変わる |

**揺れの源は一貫して「問いの曖昧さ」**であり、モデルの気分ではない。
`SA-F-01` と `TR-F-04` は**曖昧だと分かっていて直さなかった問い**で、
それがそのまま揺れている。これは測定が筋の通った挙動をしていることの裏付けになる。

## この測定の限界（正直に書く）

- **3回しか測っていない。** 標準偏差を名乗れる回数ではない。言えるのは
  「3回測った範囲で 0.0〜3.7 pt」まで
- **49問を完走したのは3回目だけ**で、その run には FI-F-05 の修正が入っている。
  完全に同一状態での49問2回測定は取れていない
- **boolean の4問が揺れの温床**になっている。3回目で不正解に転じた2問
  （`MK-M-06` / `XD-07`）はどちらも boolean で、母数が4問しかないため
  1問の揺れが 25 pt に見える。boolean は本数を増やすべきだった
- 揺れの原因を問いの曖昧さに帰属させているのは**揺れた問いの中身を読んだ結果**で、
  統計的に分離したものではない
